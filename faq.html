Frequently Asked Questions

Find answers to common questions about our website and projects. Click a question to reveal its answer.

What is this website about?

This website was created as part of CSC 216 Lab 2. It demonstrates HTML, CSS and JavaScript skills, including responsive design and interactive features.

What projects have we created?

Our projects include a personal landing page, responsive card grid, tip calculator, accessible contact form, dark mode toggle, Flexbox navigation bar, GitHub repository and portfolio website.

How can I switch between light and dark mode?

Click the Dark mode button in the navigation bar. Your theme preference is saved in local storage so it remains selected when you visit other pages.

How can I filter the projects?

Visit the Projects page and select a category such as HTML, CSS, JavaScript or Git. The website will display projects belonging to the selected category.

How can I contact the team?

Visit the Contact page and complete the contact form. Enter your name, a valid email address and a message containing at least 20 characters.
